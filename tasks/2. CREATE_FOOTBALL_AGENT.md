# Spec: Create the football research agent (managers, teams, football ideologies)
# Status: building (decisions answered 2026-10-12)

## Overview
The football catalogs need profiles for managers, teams and football ideologies. The repo already has an agent for political profiles (`/new-personality`, `/new-country`, `/new-ideology` + `profile-audit/`), but its web research is optional, unenforced and almost never saved, and the audit only sees a ~30-word description (docs/02). For football this matters more: tactical identity lives in specifics (pressing height, build-up, formations by season, quotes) that models remember badly for anyone less famous than Guardiola.

A manual test on 8 cases (docs/03, docs/04) showed what the agent must do differently: pin down the period first, read sources instead of search summaries, rank sources, keep the manager's words apart from the team's behaviour, and write down confidence and gaps. This spec turns those findings into the agent.

## In scope
- Adapt the existing `/new-*` skills and `profile-audit/` into football versions: `/new-manager`, `/new-team`, `/new-football-ideology`.
- A mandatory research step before every audit, following the method in docs/03 (steps 0–5 and rules 1–14).
- A saved research file for every profile, read by the audit prompt.
- Football-specific audit guidance and anchor profiles in the validator.

## Out of scope (v1)
- Players (decision 2026-10-12, docs/02).
- Writing the question pool (20 statements per axis, separate spec). The axes are decided below; until the questions exist the agent stops after the research file.
- Frontend changes and catalogue pages.
- A standalone service or scheduled runs. The agent stays a Claude Code workflow.
- Religion field, book step (5b) and "answer as the regime" rule from the political pipeline.

- **Groups** replace "politicamente / socialmente / economicamente" with taticamente (1–6), filosoficamente (7–10) and na gestão (11–12).
- **Compass:** Possession (x) × Block (y), with Purpose as the strip underneath.
- **Weakest pairs to watch:** Possession × Progression (they often move together) and Player type × Progression (physical teams tend to play direct).
- The anchors are judgement, not measured. They become the anchor profiles in `validate.py` once audited (see Verification).

## Functional requirements (EARS)
- FR-1  WHEN a profile is requested, THE AGENT SHALL first verify the case exists and output a `profilePeriod` with exact start and end dates, before researching style.
- FR-2  IF the period or the subject is ambiguous (e.g. "Sundowns 2025": calendar year or 2024/25; "Shankly": the manager or 1970s Liverpool), THE AGENT SHALL list the ambiguity and ask the user instead of picking one.
- FR-3  WHEN profiling a manager, THE AGENT SHALL count every spell that built their reputation, exclude spells where tactics didn't define them, and record both lists in the research file.
- FR-4  THE AGENT SHALL research by the fixed dimensions (shape, build-up, possession, pressing, defensive block & line, transitions, width & attacking patterns, set pieces, game management, manager's stated view, player profile, squad building, people management) and record a gap for every dimension without evidence.
- FR-15 THE AGENT SHALL check that each of the 12 axes is fed by at least one verified fact, and list the axes that aren't as gaps, so the audit knows which answers rest on memory alone.
- FR-5  THE AGENT SHALL use search results only to find sources. A fact SHALL count as verified only if it was read on the source page, ideally as a verbatim quote.
- FR-6  Every fact SHALL record its source URL, source tier (A–D), article date, event date and verified flag, and SHALL be checked against the target period.
- FR-7  WHEN the subject is from a non-English football culture, THE AGENT SHALL also search in the local language.
- FR-8  IF a source is blocked, empty or dead, THE AGENT SHALL try the known fallbacks (mirrors such as `legacy.` subdomains or `inside.fifa.com`, archive copies) and record the page as unreadable if they fail, never skip it silently.
- FR-9  THE AGENT SHALL record the manager's stated view separately from what the team does, with dates, and keep any contradiction with the press label.
- FR-10 WHEN using a quote, THE AGENT SHALL record the earliest verifiable source and date, and mark it "attributed" if no primary source exists.
- FR-11 For historical profiles, THE AGENT SHALL prefer sources that quote people from the time and mark claims found only in retrospectives.
- FR-12 THE AGENT SHALL end each research run with a confidence level (high / medium / low), the gaps, and open questions for the user.
- FR-13 THE AGENT SHALL save the research to `profile-audit/research/<catalog>/<id>.json` and pass it into the audit prompt (not only the short description).
- FR-14 The audit SHALL keep the existing method: a strong model answers every question independently "as" the profile, never working back from a target value, and `validate.py` checks the output against football anchor profiles.

## Acceptance criteria (examples the agent must satisfy, from docs/04)
- Pedro Emanuel – Vasco 2026 -> period starts 2026-07-11; notes the earlier Diniz and Renato spells in "Vasco 2026"; confidence low
- Miguel Cardoso – Sundowns 2025 -> asks: calendar 2025 or the 2024/25 season?
- Shankly – Liverpool -> asks: Shankly 1959–74 or 1970s Liverpool (mostly Paisley)?
- Renato's "quem sabe, sabe… quem não sabe, vai estudar" -> dated 2016-12-08 (Gazeta Esportiva), not 2017
- Klopp – Liverpool 2021/22 -> no "mid-block" claim (it came from a search summary; the source says higher press and a high line)
- Guardiola – City 2017/18 -> positional play, not tiki-taka; Guardiola's rejection of "tiki-taka" recorded under stated view
- Shankly's "socialism" quote -> marked attributed, earliest dated appearance 1995
- A fact seen only in a search summary -> `verified: false`
- FBref returns 403 -> listed under unreadable sources, season numbers taken from articles that quote them
- Renato Gaúcho – Grêmio 2017 -> evidence for Who decides (talent: player management over a codified system) and Leadership; any axis with no verified fact listed as a gap

## Non-functional
- Expect roughly 3 searches and 3 page reads per case (manual test average); a famous case can stop earlier, a small or recent one needs more.
- Long pages are read in parts (the page reader truncates at ~100k characters).
- Profiles must be reproducible: two sessions profiling the same subject use the same period and spells, because both are written in the research file.

## Data
Research file, extending the existing format (`id`, `researchedOn`, `profilePeriod`, `scopeNote`, `sources[]`):
- `catalog`: manager | team | football-ideology
- `profilePeriod`: { start, end }; managers also `spellsCounted[]`, `spellsExcluded[]` (club, dates, reason)
- `ambiguities[]`, `openQuestions[]`
- `sources[]`: title, url, tier, language, articleDate, eventDate, accessedOn, dimension, evidence (quote), verified
- `statedView[]`: quote, date, source, provenance (primary | attributed)
- `unreadable[]`: url, reason (403, empty, 404, truncated)
- `gaps[]`: dimensions and axes without evidence
- `influences[]` (optional): manager or team this one learned from (e.g. Michels → Coutinho)
- `confidence`: high | medium | low, with a one-line reason

## Verification
- Re-run the 8 test cases of docs/04 through the agent and compare against the manual results: same periods, same flagged ambiguities, no unverified fact marked verified, confidence within one level.
- `validate.py` passes on each research file's schema (new check) and on each audit.
- Axes check: after about 30 audited profiles (the docs/04 cases plus the anchors above), compute the correlation between every pair of axes. Merge or rethink any pair above about 0.7, and confirm each anchor lands on its expected pole.

## Decisions (answered 2026-10-12)
- **Unit of a profile:** both catalogs. "Klopp" is a manager profile (whole "known for" career); "Liverpool 2021/22" is a team profile scoped to that era. The two are linked by id, never by team name: the team file has `managers: [{ managerId, start, end }]`, and the manager file may list `teamProfiles[]` ids.
- **Minimum evidence:** about half a season (~15 competitive matches). Below that, the agent stops and asks the user. Above it, low confidence is allowed and saved with a warning.
- **Spell weighting:** counted spells weigh the same. "Known for" test: a spell counts if it brought major titles, a recognisable style with tactical coverage, or a move to a bigger job.
- **Source whitelist:** deferred. v1 ranks sources by tier after searching; restricting the search to quality domains is a fallback used when results are junk.
- **Football ideology names:** political words are allowed when that is how an idea is popularly known.
- **Question pool:** deferred to its own spec. Until it exists the agent stops after the research file.
- **Squad axis:** reframed as Youth ↔ Experience (who the manager gives minutes to). The key stays `bas`. Anchors confirmed 2026-10-12 after a squad-building research run on each (Juventus 2014–19 is the weakest: it reflects the club's signing policy as much as Allegri's choices).
- **Language:** the new skills, guide and research files are in English; quotes stay in their original language.
