| Political | Football |
|---|---|
| ideology / `Ideology*` / `ideologyId` | football ideology / `FootballIdeology*` / `footballIdeologyId` (API type `football-ideology`) |
| personality / `Personality*` / `personalityId` | manager / `Manager*` / `managerId` |
| country / `Country*` / `countryId` | team / `Team*` / `teamId` |
| political / social / economic dimensions | `tactics` (pos pro est lar blo mar) / `philosophy` (pla res sis jog) / `management` (bas lid) |
