## Cost and throughput (measured)

- Research with the `football-researcher` agent: about 50–100k tokens and about 3% of a session each. Audit with `football-auditor`: about 40k tokens, about 1.5% each (about 6% per batch of 4). Catalog texts, vectors and images are small by comparison.
- All 8 ideologies were researched in parallel and then audited in parallel without trouble. The web-search cap shared by all agents (200 per session) ran out once during an 8-team batch, so large parallel research batches can leave gap passes refused. Wikimedia returns 429 after about 5 quick requests: wait 3 s between calls and back off.
- Agents must name scratch scripts after the id, because they share the scratchpad and overwrite each other's files.

## Environment (for a fresh session)

- **Background removal:** `~/.venvs/rembg/bin/rembg i -m u2net_human_seg <in.png> <out.png>`. Already installed with models cached in `~/.rembg/models/`; do not ask to install again (saved in memory).
- **Run the app:** backend `cd backend && sh mvnw -o compile exec:java` (port 8080), frontend `cd frontend && npm run dev` (port 5173). Plain `curl` to the API gets 403: use browser headers (`Origin`, `User-Agent`, `Sec-Fetch-Site`) or the browser. Services stop when the session ends.
- **Tests:** `cd backend && sh mvnw -o -q test`, then sum `backend/target/surefire-reports/*.txt` (the quiet run prints nothing on success). Frontend: `npm run lint`, `npm test`, `npx tsc --noEmit`. i18n: `python3 scripts/check_i18n.py`.
- **Workflow for a new profile:** `/new-manager`, `/new-team` or `/new-football-ideology` launch the `football-researcher` agent (the main session must not research); then `python3 profile-audit/audit_prompt.py <catalog> <id>` builds the prompt, the `football-auditor` agent gets only the prompt path, then `python3 profile-audit/validate.py audit <catalog> <id>`.
- **Vector check, archive and catalog entries were done with throwaway scripts** in the old session's scratchpad, which is gone. Worth adding a small checked-in script (anchors from `FOOTBALL_AXIS_POLES`, closest pairs by RMS across the 12 axes, copy to `answers/` and append vectors) instead of rewriting it each time.
