## Part 2: cut the token cost of research

Opus subagents cost ~95–155k tokens per research profile, ~60k per audit and ~37–55k per 5-question archetype run. Plan:
1. **Custom agent** `.claude/agents/football-researcher.md`: `model: sonnet`, tools limited to Read, Write, Bash (validator and script), WebSearch, WebFetch. No browser tools (one agent dumped whole pages through Chrome).
2. **Short brief** (1–2 pages) for agents instead of reading `SKILL.md` + the full `FOOTBALL_RESEARCH.md`.
3. **`profile-audit/miner.py`** run with `uv run` (inline dependencies): takes URLs (found by the agent with WebSearch; a Tavily key is the alternative if the user prefers), fetches them, extracts the main text and publication date with `trafilatura`, keeps paragraphs that match a per-dimension keyword list (EN, PT, ES, DE, HU) plus one neighbour, caps the number per page, tries the Wayback Machine on 403, caches pages on disk, and writes `profile-audit/raw/<catalog>/<id>.md` (URL, title, date, status, tagged verbatim paragraphs, unreadable list).
4. Agent flow: build searches per dimension → run the script → read the digest → write the JSON → validate → at most one gap pass for axes in `gaps`.
5. Test on one profile with a good existing file (Herbert Chapman), compare tokens and quality, then update `FOOTBALL_RESEARCH.md` and the `/new-*` skills.
6. Budget per profile: about 8 searches and 12 pages; batches of 4–5.

Open choice for the user: searching via WebSearch + script (no key) or a Tavily key.

Order suggested: finish the 32 runs above on Sonnet first (they need no web research), then build and test the miner.
