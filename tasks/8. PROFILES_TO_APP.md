# Putting the researched profiles into the app

Status: written 2026-10-17. Nothing below is done yet except where marked.

All six backend catalogs are `[]` (`managers.json`, `teams.json`, `football-ideologies.json` and their `*-profiles.json`). The backend refuses to start if a catalog id has no profile or a profile id has no catalog entry (`QuizDataService.validateProfiles`), so each profile has to be added in full.

## Done

- Research files: 7 ideologies, 8 managers, 21 teams in `profile-audit/research/`. Axis coverage per team is in the session notes; the six first-batch teams (Ajax, Inter, Man United, Milan 2006–07, Arsenal, Juventus) were redone and are still low confidence.
- Audit tools (steps 1–3 of `profile-audit/FOOTBALL_AUDIT.md`): `audit_prompt.py`, `profile_vector.py`, `validate.py audit`, tests in `tests/test_audit.py`. Uncommitted.
- 60-question pool (5 per axis) approved as enough.
